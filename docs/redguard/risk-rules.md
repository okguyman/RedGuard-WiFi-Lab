# 配置风险提示与未知项

设备界面版本 0.5.1。先执行被动扫描，回首页选择“Wi-Fi 安全检测”。列表沿用信道过滤；选择热点进入两页说明，上移/下移选择“查看另一页”或“返回”，中间抬手确认。

仅评估 SDK 快照与被动 RSN 观测中的广播配置，不发送攻击、密码测试或关联请求。认证与套件的数字映射通过编译期断言核对固定 ESP-IDF 头文件，未知值不会自动评为安全。

| 观察 | 提示 |
| --- | --- |
| 开放未认证网络 | 优先整改；没有无线链路加密（网页门户不能替代链路加密） |
| WEP、WPA、WPA/WPA2 混合或 WPA-Enterprise | 优先整改：包含过时方式 |
| 单播或组播套件含 WEP/TKIP/TKIP+CCMP | 优先整改：包含过时套件 |
| WPA2/WPA3 过渡模式 | 明确显示兼容过渡，不自动等同于漏洞 |
| 现代已支持认证，且单播和组播都是 CCMP/GCMP 类 | 已查项未见风险，不等同于安全 |
| SDK 出现 WPS 广播标志 | 需要到路由器核查，无需使用时关闭；不是已证实漏洞 |
| PMF 未声明支持或仅可选 | 兼容时要求 PMF；这是加固建议，不证明可利用漏洞 |
| PMF 声明位异常或观测声明冲突 | 需要核查，不据此认定恶意热点 |
| 未支持认证、缺少/不一致套件 | 信息不足，不能当作通过 |

OWE 是有加密的增强开放网络，不按未加密开放网络处理。企业网络的 EAP 方法、证书验证和 RADIUS 不在扫描范围内，即使认证枚举可识别，也不能据此完成企业安全审计。

第二页显示实际 PMF 观测状态，并保留密码未测试、路由器固件与隔离未测试。新增“已知配置项 x/4”：分别计认证枚举可识别、单播/组播套件可解释、明确 PMF 能力位、出现 WPS 广播标志。未知/缺失/冲突不算明确 PMF；未见 WPS 不计为已知关闭。该计数衡量有限广播观测是否明确，**不是安全得分或完整审计覆盖率**，即使 4/4 也可能有风险。详见 `pmf-observation.md`。尚无 CVE 检查、完整 RSN 扩展解析或综合安全分数。无扫描结果时请先扫描；过滤为空时可先切回全部信道。

依据：本地固定 SDK 头文件 `esp_wifi_types_generic.h` 对认证及套件的定义；[Espressif 扫描文档](https://docs.espressif.com/projects/esp-idf/en/v5.5.1/esp32/api-guides/wifi.html)。显示的是 SDK 观测结果，未进行握手或真实连接验证。

实机待验：两页返回与长按导航、未知字段、开放与过渡模式、WPS 观测一致性、64 条密集快照、重复进出原版驱动。页面预览全部为合成样例，不是实机证据。
