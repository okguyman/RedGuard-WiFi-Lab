# 离线密码与弱词库评估（第五阶段第一部分）

本工具适用于本人或已同意测试者主动提供的口令。它不扫描无线网络、不连接路由器、不验证输入是否就是某个热点的真实密码。

## 使用

在 Mac 交互式终端进入仓库，运行 `python3 tools/redguard_audit.py password`，按提示输入口令。输入不回显。工具拒绝从命令行参数或管道读取密码，无法隐藏输入时停止。

可选词库导入：`python3 tools/redguard_audit.py import /path/to/weakwords.txt`。UTF-8 文本每行一个词，支持 BOM 和 CRLF；忽略空行，保留词内与首尾空格。不把真实的个人密码集当作词库。导入最多 16 MiB、100000 个非空行，每行含换行最多 1024 字节；控制字符或无效编码会拒绝整个导入。去重后写入 SQLite，在事务完成后原子替换原库；失败保持旧库不变。

词库默认在 `.redguard-local/weakwords.sqlite3`，Git 已忽略此目录。仅保存 NFKC/大小写折叠后的 SHA-256 弱词摘要，用于查表，不保存词库明文；这些摘要仍可能通过枚举恢复，不能把它当作机密密码保管库。`--db` 可指定数据库位置，但不能把个人词库提交到 Git。格式不受支持的 SQLite 文件被拒绝。

报告示例：`python3 tools/redguard_audit.py password --report .redguard-local/report.json`。父目录需已存在，目标文件需不存在；文件权限 0600。报告不含输入口令、其摘要、弱词命中内容或热点身份，只记录判定、原因、建议与词库条目数。不指定 `--report` 时不保存报告。Python 无法保证在退出前擦除不可变字符串的内存。

## 判定规则与边界

- 支持检查 8–63 位可打印 ASCII Wi-Fi passphrase；这只是本工具支持范围，非 ASCII 的设备兼容性需要另查。
- 64 位十六进制输入标为原始 PSK，不把“看起来随机”当作生成质量证明。
- 内置 22 个自行整理的示例弱词。可选导入覆盖更多弱词，未导入时会说明覆盖数量。
- 词库匹配使用 NFKC 与大小写折叠；也检查词尾仅追加数字/符号且主体至少 4 位的简单变体。不会改变真实输入用于连接，因为本工具完全不连接。
- 提示不足 16 位、纯数字、短片段重复、常见连续六位数字/字母/键盘序列。16 位是项目的保守建议阈值，不声称是 Wi-Fi 协议或 NIST 强制要求。
- 不要求机械凑齐大小写数字符号，不输出熵值、破解时间或“保证安全”的评分。多个随机无关词也可用于长口令，但本工具无法证明选词随机。
- 不检测全部变体、个人信息、口令复用或完整泄漏数据。即使显示“已查项未发现明显弱点”，仍需独立随机生成且不复用。

设计参考：[NIST 关于密码长度、常见弱口令和组成规则的说明](https://pages.nist.gov/800-63-4/sp800-63b/passwords/)。该说明是通用数字身份指导，不是本工具 Wi-Fi 兼容性或合规认证。

## 验收

`python3 tools/redguard_test.py` 包含词库归一化/去重、简单尾缀、报告脱敏、导入失败保留旧库、上限、拒绝未知数据库、禁止报告覆盖等测试。使用的测试字符串是合成示例，不是真实用户密码。
