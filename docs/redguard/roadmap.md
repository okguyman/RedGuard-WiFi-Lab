# 分阶段开发路线

1. **编译基线**：固定官方 v1.18.0、CYD 双 USB 配置。已完成本地编译；原版官方固件此前在板上正常显示与触摸。
2. **中文竖屏**：中文首页、字库子集、原版三区域触控。代码与本地测试完成，新增固件实机回归待做。
3. **品牌启动**：折线红盾、轻量静态启动、中文步骤提示。代码与编译完成，真实启动耗时待测。
4. **被动分析**：异步扫描、排序、过滤、详情、信道图与 USB CSV。代码完成；实机验收待做。连续趋势和 SDK 不提供的字段不能冒称已实现。
5. **配置/密码评估**：广播认证/套件/WPS 的可解释提示与未知项页已实现；Mac 离线密码评估、弱词库导入与脱敏 JSON 报告已实现并测试。顶层 RSN 的 PMF 广播位解析及 4 项观测计数已实现并有边界测试；设备实机验证与完整 RSN 套件/扩展解析仍待做，不提供伪精确综合安全分数。板上不直接输入或保存密码。
6. **BLE/报告/设置**：新 BLE 页面、随机地址说明、JSON 报告、整改复查与设置。未实现。
7. **发布验收**：真实硬件稳定性、内存/任务栈、驱动冲突回归；备份并确认刷机方案后刷写。尚未完成。

后续风险检查优先级：过时认证与密码套件 → PMF/WPS 可观察声明 → 同名热点与基线变化提示 → 本人或已同意测试的朋友主动提供的密码评估 → 整改前后报告。不能把同名热点认定成恶意热点，也不能把未观察到风险认定成网络安全。

路由器固件 CVE、管理后台、DNS/DHCP 和访客隔离需要准确设备信息或 Mac/受控终端协助，不根据 SSID 猜测。经典 ESP32 只覆盖 2.4 GHz。

不加入对店家或附近第三方网络的自动口令猜测，不伪装登录页面收集密码。店家公开凭据/二维码的便捷连接属于独立方向；本项目不以“消费了就获得测试授权”为前提。
