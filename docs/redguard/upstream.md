# 上游来源与发布范围

项目基线来自 https://github.com/justcallmekoko/ESP32Marauder ，tag `v1.18.0`，提交 `b2b9f92382eb60b39b8741be3b567e416cdbe672`。

本仓库是基于该版本的源码快照与 RedGuard 修改，不宣称是 GitHub 的官方 fork，也不伪造完整上游提交历史。保留原始许可证、版权声明、当前固件全部功能源码、构建所需库/配置、测试、安装器元数据与上游工作流。

为避免个人开发仓库包含数百 MB 无关历史资料，发布快照不包含原仓库的机械 CAD、PCB 归档、大量历史照片、Windows 刷机工具包、旧固件二进制及 `PreviousVersions`。这些资料仍可在上述官方仓库查阅；本地上游克隆未删除。该精简不删除当前固件功能。

RedGuard 的新增模块和改动同样按项目根目录 MIT 许可证提供；依赖库和字体分别遵循其原有许可证。字体许可见 `assets/redguard/OFL.txt`。
